Warm-up · Largest of three numbers

Start with the first value as the largest. Compare it with the next two values and update it whenever you find a larger number.

View C source
#include <stdio.h>

int main(void) {
    int a, b, c;
    if (scanf("%d %d %d", &a, &b, &c) != 3) {
        return 1;
    }

    int largest = a;
    if (b > largest) largest = b;
    if (c > largest) largest = c;

    printf("Largest: %d\n", largest);
    return 0;
}
